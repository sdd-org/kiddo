# Contributors

Kiddo is developed and maintained by Scott Donnelly, with contributions from
the community. We gratefully acknowledge the following contributors, listed
alphabetically by GitHub username:

- **Carlson Büth** ([cbueth](https://github.com/cbueth)):
  small-k nearest-neighbour result-collection improvements, performance
  investigations, fixes, and regression tests.
- **Chris Barnes** ([clbarnes](https://github.com/clbarnes)):
  tree iteration and optional `rand` and `rayon` dependencies in pre-v6 versions.
- **Francisco Couzo** ([franciscouzo](https://github.com/franciscouzo)):
  the WebAssembly SIMD128 leaf-kernel backend and its tests and CI coverage.
- **Jules Bertholet** ([Jules-Bertholet](https://github.com/Jules-Bertholet)):
  `FromIterator` and `Extend` implementations in pre-v6 versions.
- **Perry Kundert** ([pjkundert](https://github.com/pjkundert)):
  more flexible payload types, tree-size semantics, and nearest-point coordinate
  access in pre-v6 versions.

These acknowledgements cover contributions across Kiddo's history, including
earlier versions. This list is not exhaustive: thanks also to everyone who has
contributed code, tests, documentation, bug reports, and discussions. See the
[GitHub contributors page](https://github.com/sdd-org/kiddo/graphs/contributors)
for more of the project's development history.
